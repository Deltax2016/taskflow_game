# TaskFlow — обзор продукта

TaskFlow — это SaaS для управления задачами и проектами для небольших команд.
Основные сущности: проекты, доски (канбан), задачи, комментарии и участники.

## Ключевые возможности

- Канбан-доски с колонками и перетаскиванием задач.
- Списки задач с приоритетами, метками и сроками.
- Совместная работа: назначение исполнителей, комментарии, упоминания через @.
- Уведомления по email и в веб-интерфейсе.
- Мобильное приложение для iOS и Android.

## Поддерживаемые браузеры

TaskFlow работает в последних версиях Chrome, Firefox, Safari и Edge.
Internet Explorer не поддерживается.
