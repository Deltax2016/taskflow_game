# Интеграции

TaskFlow интегрируется с популярными сервисами (доступно на тарифах Pro и Business).

## Доступные интеграции

- **Slack** — уведомления о задачах в каналы, создание задач из сообщений.
- **Google Calendar** — синхронизация сроков задач с календарём.
- **GitHub** — привязка задач к коммитам и pull request'ам.
- **Telegram** — бот для уведомлений о назначенных задачах.

## Как подключить интеграцию

1. Откройте «Настройки → Интеграции».
2. Выберите сервис и нажмите «Подключить».
3. Авторизуйтесь во всплывающем окне и подтвердите доступ.

## API и вебхуки

На тарифе Business доступен REST API и исходящие вебхуки.
Токен API создаётся в разделе «Настройки → API».
